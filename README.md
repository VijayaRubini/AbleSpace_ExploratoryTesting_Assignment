# AbleSpace_ExploratoryTesting_Assignment

Application name: AbleSpace

Environment: staging.ablepace.io

Tested By: Vijaya Rubini

Testing type: Manual Exploratory testing, Cross browser testing

Browser/ Device -Microsoft Edge, Google Chrome, Mobile Application



Manual exploratory testing of the AbleSpace application was performed on Google Chrome and Microsoft Edge using a desktop PC, along with mobile application and device testing. The testing covered account creation and login, navigation, account settings, roles and permissions, student and group management, reports, collaborator management, search and filters, session and activity logs, and data persistence. Most of the tested core functionalities worked as expected.

A total of 5 distinct defects were documented. The most critical issue was the inability to log in across mobile and desktop platforms using the same account. This defect was assigned high severity and priority because it affects account accessibility across devices. Other issues included incorrect group view behaviour, inconsistent page titles, duplicate error messages during repeated clicks, and a spelling mistake in a validation message. The recorded test cases included 12 passes and 3 failures.
